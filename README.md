# 📝Todo App

A **Full-Stack Todo Application** built using the **MERN stack (MongoDB, Express.js, React, Node.js)** with full **CRUD functionality**.  
The app allows users to create, read, update, and delete todos in real time.  
Frontend is hosted on **Netlify**, and the backend API is deployed on **Render**.

---

## 🌐 Live Demo

- **Frontend (React + Vite + Bootstrap):** [https://tiny-mermaid-3e47c0.netlify.app/](https://tiny-mermaid-3e47c0.netlify.app/)  
- **Backend API (Express + MongoDB):** [https://todo-app-backend-84b3.onrender.com/api](https://todo-app-backend-84b3.onrender.com/api)

---

## 🚀 Features

- ✅ Add new todos  
- ✏️ Edit existing todos  
- ❌ Delete todos  
- 📋 View all todos in a clean UI  
- 📱 Responsive layout using **Bootstrap**  
- 🌍 Backend connected to **MongoDB Atlas**  
- ⚡ Hosted frontend on **Netlify** and backend on **Render**
